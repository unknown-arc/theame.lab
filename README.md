# **THEME LAB — IITP Moodle Theme**

THEME LAB is a Chrome extension designed to transform the IIT Patna Moodle interface into a cleaner, modern, and more user-friendly learning environment.

It improves the visual experience with customizable themes, responsive layouts, better navigation, and performance-focused UI enhancements while keeping Moodle's core functionality intact.

## ✨ Features

- 🎨 Modern and clean Moodle interface
- 🌙 Light and dark themes
- 🖼️ Custom background support
- 📚 Improved course interface
- 👤 Enhanced user and navigation components
- 📱 Responsive design
- ⚡ Performance-focused CSS and JavaScript
- 🔧 Configurable styles and scripts
- 🐛 Debug support
- 🔄 Page-specific UI enhancements

## 🎯 Supported Platform

**Current target:** IIT Patna Moodle

THEME LAB is developed around the IIT Patna Moodle environment. Compatibility with other Moodle installations is not guaranteed because Moodle versions, themes, plugins, and page structures can differ.

## 🛠️ Installation

1. Download or clone this repository.
2. Open `chrome://extensions/` in Google Chrome.
3. Enable **Developer mode**.
4. Click **Load unpacked**.
5. Select the THEME LAB project folder.
6. Open the supported IIT Patna Moodle website.

The extension will load automatically on supported pages.

## 🖥️ Using THEME LAB

After installation, open IIT Patna Moodle and use the extension's available controls to customize the interface.

Depending on the current version, customization may include:

- Theme selection
- Background settings
- UI preferences
