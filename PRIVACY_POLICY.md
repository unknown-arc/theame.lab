Privacy Policy for THEME.BY — IITP Moodle Theme
Effective Date: August 4, 2026

THEME.BY — IITP Moodle Theme ("we," "our," or "us") is committed to respecting and protecting your privacy. This Privacy Policy explains our data practices regarding our Chrome extension.

1. Zero Data Collection
We do not collect, store, track, sell, or transmit any personally identifiable information (PII) or sensitive user data.

All operations performed by the extension happen locally within your web browser.

2. Local Storage Usage
The extension uses the standard browser chrome.storage.local API solely to save your local visual preferences (such as custom theme selections, dark/light mode toggles, or layout settings).

This data remains strictly stored on your device.

It is never uploaded to any external server or shared with third parties.

3. Permissions & Host Access
Host Permissions ([https://moodle.iitp.ac.in/](https://moodle.iitp.ac.in/)*): Used exclusively to inject custom CSS styles and UI scripts into the IIT Patna Moodle portal to render the enhanced interface.

Storage Permission: Used exclusively to store your UI preferences locally on your browser.

4. Third-Party Services
The extension does not contain any third-party analytics, tracking tools, advertisements, or remote code dependencies.

5. Changes to This Policy
If we make minor updates to this Privacy Policy, the revised version will be published on this page with an updated effective date.

6. Contact Us
If you have any questions or concerns regarding this Privacy Policy, please feel free to reach out via GitHub or through the Chrome Web Store developer contact form.
